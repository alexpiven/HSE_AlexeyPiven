
### **Мануал по использованию программы обработки реестра экстремистских материалов**

#### **Назначение**
Программа автоматизирует процесс получения, парсинга, статистического анализа и предоставления интерактивного доступа к данным из реестра экстремистских материалов.

#### **Источник данных**

Федеральный список экстремистских материалов Министерства Юстиции  РФ
https://data.gov.ru/datasets/fb7c0246-ae56-4685-bbeb-2fa6778b8955

#### **Структура проекта**
```
ваша_директория/
├── main.py          # Главный файл запуска
├── loader.py        # Модуль загрузки CSV-файла
├── parser.py        # Модуль парсинга данных
├── statistics.py    # Модуль генерации статистики
├── content_extrem.py # Модуль работы с собранными данными
├── content_categories.py # Словарь категорий
└── data/            # Папка для хранения скачанных CSV-файлов
```

#### **Запуск**
1.  Убедитесь, что все файлы и папки находятся в нужных местах.
2.  Откройте терминал или командную строку.
3.  Перейдите в директорию с проектом: `cd путь/к/вашей_директории`
4.  Запустите главный файл: `python main.py`

#### **Процесс работы программы**
1.  **Скачивание:** Программа автоматически скачивает последнюю версию CSV-файла с реестра и сохраняет его в папку `data/`.
2.  **Парсинг:** Данные из CSV-файла обрабатываются, извлекается информация (категория, URL, суд, даты) и сохраняются в файл `parsed_data.json`.
3.  **Статистика:** Генерируется краткая статистика по количеству записей, судам и сезонам внесения.
4.  **Интерактивное меню:** Открывается главное меню для работы с данными.

#### **Интерактивное меню**
После завершения предыдущих шагов, программа предложит выбрать действие:

*   **1. Показать материалы по категории:**
    *   Программа выведет список доступных категорий (например, `книга`, `видеозапись`, `текстовый материал`). Введите **точное** название одной из них.
    *   Будет показан список материалов, отнесённых к этой категории.
*   **2. Получить случайный материал (Описание/URL):**
    *   Программа выберет случайный материал, содержащий URL, и выведет его описание и первый URL.
*   **3. Показать материалы по суду и году:**
    *   Программа выведет список известных судов (первые 10).
    *   Введите **точное** название суда (например, `Верховный Суд`).
    *   Введите год (например, `2023`).
    *   Будет показан список материалов, внесённых по решению этого суда в указанный год.
*   **4. Показать материалы за последний месяц:**
    *   Программа покажет список материалов, дата включения которых в реестр (`registry_inclusion_date`) попадает в последний календарный месяц.
*   **5. Выход:**
    *   Завершает работу программы.

#### **Важные замечания**
*   Для поиска по категории и суду важно вводить точное название, как оно отображается в подсказке.
*   Некоторые данные в реестре могут быть отсутствовать (например, `'неизвестно'`), что отражается в результатах.
*   Программа использует `parsed_data.json` как основное хранилище для поиска и фильтрации. Этот файл перезаписывается при каждом запуске парсера.
